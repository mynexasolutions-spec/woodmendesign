## ⚡ Interactive Features

- **Slide-over Shopping Cart Drawer**:
  - Live item count badge
  - Quantity increment/decrement and removal
  - Subtotal and free shipping progress meter
  - Coupon support: enter `WOODMEN10` for 10% off!
- **Checkout Modal**:
  - Customer delivery details (Name, Phone, Address, PIN code)
  - Payment mode options (Cash on Delivery, UPI / GPay, Cards)
  - Instant order confirmation screen with tracking ID and celebration confetti!
- **Quick View Modal**:
  - In-depth product view, wood species specifications, dimensions, care guide, quantity picker, and direct WhatsApp inquiry link.
- **Search Modal**:
  - Live instant search across titles, categories, wood types, and descriptions with keyboard shortcuts (`Esc`).
- **Crafting Video Modal**:
  - Artisan workshop narrative detailing the 3-step creation journey from raw timber to finished tableware.

## 🚀 Running the Project

```bash
# 1. Install dependencies (if not already installed)
npm install

# 2. Run development server
npm run dev

# 3. Build for production
npm run build

# 4. Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the website in your browser.
